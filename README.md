# HOH Revestimentos

Landing page para a **HOH Revestimentos**, empresa especializada em aplicação de papéis de parede de alto padrão sem obras em Curitiba-PR e Florianópolis-SC.

## 🚀 Tecnologias

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
- JavaScript (Vanilla)
- Google Fonts (Cinzel & Outfit)

## 📁 Estrutura do Projeto

```text
.
├── index.html     # Estrutura HTML e estilos Tailwind
└── js/
    └── app.js     # Lógica de interatividade (FAQ, modal, menus)
```

## 🛠️ Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador web ou utilizar uma extensão como o *Live Server* no VS Code.
